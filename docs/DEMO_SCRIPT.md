# Demo Script (6-7 minutes)

Record your screen with a real API key. Keep a small PDF syllabus (3+ pages) ready, plus a second,
different PDF for the replacement step.

| Time | Do this | Say / show |
|---|---|---|
| 0:00 | Open the app | "Goal, skills, level, hours, duration go in; a checked roadmap comes out." Mention the module structure briefly. |
| 0:30 | Goal "Become a Data Analyst", Beginner, 8 h x 8 weeks, no PDF. Generate. | Progress bar while it streams. Point out the **reality-check banner**: the app compared 64 hours with the goal and the plan says what *is* achievable. |
| 1:30 | Scroll the plan | Weekly tables with hours, milestones. Show the line "Checked: 8 weeks - busiest week X h (limit 8 h)". Open "Notes from the plan check". |
| 2:00 | Resources table | Only links marked verified are clickable; others say "could not verify" or "search the exact title". Click one verified link. |
| 2:30 | Sidebar: upload syllabus PDF, **Index this PDF**, regenerate | "The PDF now shapes the plan." Show "Document reference: file, p. N" under weeks. |
| 3:15 | Coach tab: ask a question about prerequisites | Answer cites file and page; open "Sources". |
| 3:45 | **Revise the roadmap**: "I can only study 5 hours a week from now on." Draft. | Show the change summary and preview. Point out the Roadmap tab has **not** changed yet. Click **Apply revised roadmap**; then show the Roadmap tab, the download, and the tracker all updated. |
| 4:45 | Progress tab | Tick a few tasks (they came from the roadmap). Back in Coach ask "Am I on track?" - the answer uses what is done. Export progress, refresh the page, restore it. |
| 5:45 | Replace the PDF with a different one | Old index clears immediately; index the new file; ask a question - answers come only from the new file. Remove the PDF (X) - index clears. |
| 6:30 | Failure handling (optional) | Disconnect Wi-Fi mid-answer: friendly message, partial answer not saved, **Retry** button. Reconnect and retry. |
| 6:45 | Show the tests | Run `python -m pytest -v` and show 100 tests passing; open `docs/TEST_EVIDENCE.md`. |

Tips: do the live matrix cases in `docs/TEST_EVIDENCE.md` before recording so you know the outcomes,
and fill in that table with what you actually observe.
